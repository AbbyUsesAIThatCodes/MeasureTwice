# MeasureTwice

A measuring game for **Design And Modeling, Activity 1.3 — Measuring Matters**.

Read a requested length in inches, click its position on a virtual ruler, and watch a piece of wood enter a cutting machine. The correctly cut piece remains, visibly duplicates into the quantity the model needs, and flies into place in a recognizable model built from simple shapes.

**Measure each distinct length once per build.** Repeated pieces come from visible duplication, not repeated identical questions.
