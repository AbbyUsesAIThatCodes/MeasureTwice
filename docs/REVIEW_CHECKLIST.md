# Quick Review Checklist

Use the integrated review directory named in the latest draft PR. Run `node serve.mjs . 18443` inside it or double-click `Start Review.cmd`, then visit `http://127.0.0.1:18443`. Node must be installed. This starts a loopback-only server. Stop it before opening another snapshot on the same port. The complete build identity remains visible at the bottom.

1. In Challenge, the first family needs **1 1/4 in**. Select **1 1/8 in** (18 sixteenths) and Cut. The saw must run, the piece must swing toward you, and only then should a red missing extension and “1/8 in Too Short” appear. Wait: it must remain until Try Again.
2. Try **1 3/8 in** (22 sixteenths). Inspect excess instead. Retry **1 1/4 in** (20). Keep it: one original plus seven equal copies form four uprights and four rafters. Then cut **2 in** (32) and **1 in** (16). The completed frame contains **17 pieces from three accepted measurements**. Orbit around it; lengths do not change.
3. Repeat with Reduced Motion and Skip Animation. Inspection still needs acknowledgement. Switch modes mid-cut; return to the held result. Restart This Mode must not reset the other two modes.
4. Free Play: cut two different lengths, keep both, and Duplicate Last Piece. Starts align for comparison; the copy does not count as another measurement. Optional targets diagnose fit but never forbid keeping a mismatch.
5. Learn: choose any of the five lessons; Show Me demonstrates its ruler idea, then make a guided cut. Try With Less Help hides the solved readout. Explain the Idea collects or reviews conceptual reasoning. There are no lesson locks.
6. Challenge → Check Understanding: try all six checks. Origin and equivalence predictions are committed before cut feedback. The fit and unit checks are separate from sawing. Wrong choices are distinguishable; any written explanation is saved for **Teacher Review**, never automatically passed.
7. Curriculum and What This Practices expose original teaching summaries, source links and bold nested vocabulary. Hover or focus opens an explanation; it stays open while moving into nested definitions or reference links. Escape closes the panel.
8. Verify pointer, arrow keys, Enter, magnification, camera drag/orbit/zoom, Highlight Wood, Full Screen, mute and visible build ID on a classroom laptop.

C03 must display **Cut To 6/8 in** before any response. Read Learn lesson 3 or use Hint, then return to C03: its cut, objective and explanation records must be assisted. Inspect a house cut and Restart: the next cut stays assisted and the original record stays unchanged.
