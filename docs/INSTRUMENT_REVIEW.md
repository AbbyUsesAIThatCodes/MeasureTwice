## Exact Length Model

One canonical tick is 1/80 mm. One inch is exactly 2,032 ticks, one sixteenth inch is 127 ticks, and one millimetre is 80 ticks. The yardstick ends at 73,152 ticks; the metre stick ends at 80,000 ticks. They are deliberately different lengths. Physical geometry uses two world units per inch throughout; meshes never stretch on inspection, duplication or assembly.

Existing inch responses still store integer sixteenths. New records add the instrument, representation, visible subdivision, exact physical actual/target values and schema version. Metric responses store whole millimetres and use explicit mm labels, with exact whole-centimetre names where applicable. No decimal-centimetre lesson is implied.
